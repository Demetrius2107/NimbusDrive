## 一、API 规范（RESTful）

### 1.1 环境与版本

```yaml
# RESTful API Schema
openapi: 3.0.0
info:
  title: NimbusDrive API
  description: DOC
  version: v1
servers:
  - url: https://api.nimbusdrive.com/v1
    description: 生产环境
  - url: http://localhost:8080/api/v1
    description: 开发环境

``` 

### 1.2 基础 HTTP 状态码（全局）

| 状态码 | 说明 |
|--------|------|
| 200 | 成功，请求成功处理 |
| 201 | 创建，成功创建新资源 |
| 204 | 无响应，请求成功但无内容返回 |
| 400 | 参数错误，请求参数不合法 |
| 401 | 未授权，请求未提供或无效认证 |
| 403 | 权限拒绝，用户无此操作权限 |
| 404 | 未找到，请求的资源不存在 |
| 429 | 请求过多，速率限制被触发 |
| 500 | 服务器内部错误，服务端异常 |

## 三、核心模块接口（续）

### 2.2 下载模块

> 服务归属：TransferServer (Hertz, :8081)
> 鉴权：所有接口受 JWT 保护（Authorization: Bearer）
> 流式回写：MinIO GetObject → TransferServer → 客户端，不缓冲全量到内存

#### 2.2.1 下载文件（GET /api/v1/download/{fileId}）

**流式下载文件，支持标准 HTTP Range 请求（206 Partial Content）**

```yaml
  /api/v1/download/{fileId}:
    get:
      summary: 下载文件
      operationId: downloadFile
      tags:
        - 下载
      security:
        - BearerAuth: []
      parameters:
        - name: fileId
          in: path
          required: true
          schema:
            type: integer
            description: 文件 ID
        - name: Range
          in: header
          required: false
          schema:
            type: string
            description: 'HTTP Range 头，如 "bytes=0-4194303"、"bytes=0-"、"bytes=-99"'
      responses:
        '200':
          description: 全量下载成功
          headers:
            Content-Type:
              schema:
                type: string
            Content-Length:
              schema:
                type: integer
            Content-Disposition:
              schema:
                type: string
                description: 'attachment; filename="..." 或 RFC 5987 编码'
            Accept-Ranges:
              schema:
                type: string
                enum: [bytes]
          content:
            application/octet-stream:
              schema:
                type: string
                format: binary
        '206':
          description: Range 请求成功，返回指定字节范围
          headers:
            Content-Range:
              schema:
                type: string
                description: 'bytes {start}-{end}/{total}'
            Content-Length:
              schema:
                type: integer
            Accept-Ranges:
              schema:
                type: string
                enum: [bytes]
        '400':
          description: 文件夹不可下载 / 文件未完成上传
        '403':
          description: 无权访问此文件
        '404':
          description: 文件不存在 / 已软删除 / 无物理存储
        '500':
          description: 服务器内部错误
```

**校验逻辑**：
- 软删除（deleted_at 非空）→ 404
- 文件夹（is_folder=true）→ 400
- 状态非 completed → 400
- storage_path 为空 → 404
- 非文件所有者 → 403

**Range 格式**：
- `bytes=0-`：从 start 到末尾
- `bytes=0-99`：指定范围（end 包含）
- `bytes=-99`：最后 99 字节
- 多段 Range（`bytes=0-99,200-`）不支持，降级为全量下载

#### 2.2.2 预检文件（HEAD /api/v1/download/{fileId}）

**返回文件元信息头，不传输 body。客户端据此决定下载策略。**

```yaml
  /api/v1/download/{fileId}:
    head:
      summary: 预检文件
      operationId: headDownloadFile
      tags:
        - 下载
      security:
        - BearerAuth: []
      parameters:
        - name: fileId
          in: path
          required: true
          schema:
            type: integer
      responses:
        '200':
          description: 预检成功
          headers:
            Content-Type:
              schema:
                type: string
            Content-Length:
              schema:
                type: integer
                description: 文件总大小（字节）
            Accept-Ranges:
              schema:
                type: string
                enum: [bytes]
        '403':
          description: 无权访问
        '404':
          description: 文件不存在
```
