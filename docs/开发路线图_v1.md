### feat/upload ✅
- **状态**：已推送 feat/upload，待开 PR 合入 master
- **范围**：TransferServer 上传完整链路
  - migration 0002：`upload_sessions.upload_id` 列
  - storage/minio.go：基于 `minio.Core` 的分块上传 API
  - middleware/hertz_auth.go：Hertz JWT 鉴权
  - handler/upload_handler.go：check-hash（秒传判定+创建会话）、PUT chunk、GET missing（断点续传）、POST complete（合并+元数据事务）、DELETE cancel
  - cmd/transferserver：注入依赖 + 挂载 /upload 路由
  - web/uploader.ts：mock 替换为真实接口；SHA-256 哈希；vite 代理分流 :8081/:8080
- **设计决策**：
  - check-hash 放 TransferServer（非设计文档 7.1 的 APIServer），减少跨服务调用
  - complete 仅校验 size，不做服务端全量 SHA-256
  - 配额扣减用原子条件 UPDATE `WHERE used+delta <= quota`，事务内执行防超卖
- **待办**：完整 e2e 链路验证（需本地 PG + MinIO）

## 二、待开发（按建议优先级排序）

### feat/download（P1）🔄 进行中
- **状态**：已推送 feat/download，待开 PR 合入 master
- **服务**：TransferServer (Hertz)
- **范围**：
  - `GET /api/v1/download/:fileId`：鉴权 + 软删除/权限校验 → MinIO GetObject(range) 流式回写
  - `HEAD /api/v1/download/:fileId`：预检文件大小与类型
  - 标准 HTTP Range 头，支持 206 Partial Content（bytes=start-end / bytes=0- / bytes=-99）
  - Content-Disposition RFC 5987 编码处理中文文件名
  - 前端 downloader.ts + FilesPage 下载操作列
  - 可选 P2 优化：预签名 URL 让客户端直连 MinIO
- **依赖**：files 表读取（FileRepo.GetByID）、storage.MinIO.GetObject
- **前置**：feat/upload 合入 ✅

### feat/file-list（P1）✅
- **服务**：APIServer (Gin)
- **范围**：
  - 文件列表：`GET /files`（分页、按 parent_id）
  - 创建文件夹：`POST /files/folder`
  - 移动：`POST /files/:id/move`
  - 重命名：`POST /files/:id/rename`
  - 软删除：`DELETE /files/:id`（文件夹递归软删除）
  - 回收站列表：`GET /trash`
  - 恢复：`POST /trash/:id/restore`
  - 彻底删除：`DELETE /trash/:id`（文件夹递归硬删除 + ref_count--，触发 GC 候选）
- **Store 补充**：ListTrash、SoftDeleteRecursive、HardDeleteRecursive、ListDescendants（递归 CTE）
- **前端**：FilesPage 后端加载 + 文件夹导航 + 面包屑 + 新建/重命名/移动/删除；新增 TrashPage + 侧栏入口
- **依赖**：FileRepo 已有的 ListByParent/Move/Rename/SoftDelete/Restore/Subtree/HardDelete
- **前置**：无
- **状态**：已本地合入 master，待推送远程开 PR

### feat/share（P2）✅
- **服务**：APIServer (Gin) + Redis 缓存
- **范围**：
  - 创建分享：`POST /files/:id/share`（生成 16 字符短 ID、bcrypt 密码、过期、次数限制）
  - 我的分享列表：`GET /shares`
  - 取消分享：`DELETE /shares/:id`（清缓存）
  - 公开查看：`GET /s/:id`（不暴露密码，has_password）
  - 校验密码：`POST /s/:id/validate`（bcrypt 校验 + access_count++ + 过期判断）
  - Redis write-through 缓存：`share:{id}` Hash + TTL
- **Store 补充**：MarkExpired、GetByFile
- **Cache 补充**：SetShare/GetShare/DelShare/IncrShareAccess
- **前端**：SharesPage 重写（列表/取消/复制链接）、ShareViewPage 公开访问页（/s/:id）、FilesPage 分享入口
- **依赖**：ShareRepo（Create/Get/IncrAccess/Cancel/ListByUser + 新增 MarkExpired/GetByFile）
- **状态**：已完成，待推送远程开 PR

### test/upload（P2）✅

### feat/admin（P2）✅
- **服务**：APIServer (Gin) + GORM adminstore
- **范围**：
  - 用户管理：`GET /admin/users`（分页/搜索/状态筛选）、`PATCH /admin/users/:id/status`（封禁/解封）、`PATCH /admin/users/:id/quota`（调配额）

- **前端**：AdminPage 三 Tab（用户管理/文件审计/操作日志）+ 侧栏仅 is_admin 可见 + 登录接入真实 API 存储 is_admin
- **依赖**：adminstore (GORM)、operation_logs 表
- **状态**：已完成，待推送远程开 PR
